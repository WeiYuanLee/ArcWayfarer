ARCWAYFARER USER GUIDE

第一次使用也能
一步一步完成定位。

這份指南從安裝、連接 iPhone、開啟開發者模式，到 Teleport、路線導航與手機遙控，完整說明 ArcWayfarer 的實際操作流程。

iOS 16+macOS Apple Silicon / IntelWindows 10 / 11免越獄
開始第一次定位 → 下載 ArcWayfarer
01 · 使用前準備

開始前先確認這些條件

⌘

macOS

支援 Apple Silicon 與 Intel Mac。iOS 17+ 建立開發者服務通道時，系統可能要求額外權限。

⊞

Windows

支援 Windows 10 / 11 64-bit。請確保已安裝 iTunes 或 Apple Mobile Device Support。

◉

iPhone

支援 iOS 16 以上。需使用可傳輸資料的 USB 線，並完成「信任這部電腦」。

iPhone 17 / iOS 26.6：Apple Silicon Mac 的裝置偵測相容性問題已於 ArcWayfarer v0.1.10 修正。若仍使用較舊版本，請先更新。
02 · 安裝

下載與安裝 ArcWayfarer

請從 ArcWayfarer 官網下載最新版本，依電腦架構選擇 Apple Silicon、Intel 或 Windows 安裝檔。

1

下載正確版本

Apple Silicon 選 ARM64；Intel Mac 選 x64；Windows 使用 64-bit 安裝程式。

2

完成安裝

macOS 將 App 安裝至「應用程式」；Windows 執行安裝程式即可。

3

第一次安全性提示

macOS 若遭 Gatekeeper 阻擋，可在 Finder 對 App 按右鍵 →「打開」；Windows SmartScreen 可選「更多資訊」→「仍要執行」。

03 · 第一次啟動

看到系統權限提示是正常的

ArcWayfarer 已封裝成完整桌面 App，一般使用者不需要另外安裝 Python、Xcode 或自行執行 pymobiledevice3。

ArcWayfarer 啟動時要求的系統權限，是為了啟動底層 iPhone Developer Services 通訊環境，其中包含 pymobiledevice3 所需服務。請依系統提示允許。
04 · 裝置連線

連接你的 iPhone

1

解鎖 iPhone

保持螢幕解鎖，並以可傳輸資料的 USB 線連接電腦。

2

信任這部電腦

iPhone 跳出提示時選擇「信任」，並輸入解鎖密碼。

3

回到 ArcWayfarer

裝置通常會自動出現在裝置選擇區。多裝置時請確認目前選取的 iPhone。

找不到裝置？先換 USB 線與 USB Port，再確認 Windows 的 Apple Mobile Device Support 是否正常。
05 · 必要設定

開啟 Developer Mode／開發者模式

Developer Mode 是 ArcWayfarer 使用 iOS Developer Services 模擬定位的必要條件。

A

從 ArcWayfarer 協助開啟

若裝置尚未啟用 Developer Mode，可使用 ArcWayfarer 左上角提供的開發者模式協助功能，依畫面指示進行。

B

在 iPhone 手動開啟

前往「設定 → 隱私權與安全性 → 開發者模式」。啟用後 iPhone 會重新啟動，開機後需再次確認並輸入密碼。

設定裡沒有「開發者模式」？先將 iPhone 接上電腦並完成信任，再使用 ArcWayfarer 左上角的 Developer Mode 協助功能，之後重新檢查 iPhone 設定。
06 · QUICK START

用 Teleport 完成第一次定位

第一次測試建議先使用 Teleport。只要 Apple Maps 能正確顯示模擬位置，就代表基本環境已完成。

  1. 01
    USB 連接並選取 iPhone

    確認裝置狀態正常。

  2. 02
    確認 Developer Mode 已開啟

    尚未啟用時先完成上一節設定。

  3. 03
    搜尋地點

    例如「台北 101」，或直接點選地圖上的位置。

  4. 04
    選擇 Teleport

    執行定位後開啟 iPhone 的 Apple Maps 驗證。

第一次較久是正常的。ArcWayfarer 可能需要準備 Developer Disk Image、Developer Services 與 RemoteXPC 通道；這些流程會自動完成，不需要安裝 Xcode。
07 · 功能指南

六種移動模式

01

Teleport／瞬間移動

搜尋地點或點選地圖，立即將 iPhone 模擬位置切換到指定座標。適合快速測試不同地區。

02

Navigate／導航

建立起點到目的地的道路路線，設定步行、跑步、騎車或其他移動速度後開始移動。

03

Route Loop／路線循環

將規劃好的路線重複播放，適合長時間固定路線測試，也可搭配 GPX／JSON 匯入。

04

Multi-stop／多點路徑

依序加入多個航點，並可拖曳調整航點順序。拖曳時前後相連路徑會同步更新。

05

Joystick／搖桿

使用畫面搖桿或鍵盤即時控制方向與速度，適合需要手動探索的情境。

06

Random Walk／隨機漫步

在指定區域內持續隨機移動，適合模擬公園、社區或固定範圍活動。

08 · 常用工具

搜尋、收藏與歷史紀錄

Place Search

輸入地點名稱、地址、景點或關鍵字，搜尋結果可以直接拿來 Teleport 或建立路線。

Favorites

儲存常用位置、建立群組並拖曳排序，避免每次重新搜尋。

History

快速回到近期使用過的位置，特別適合反覆驗證多個測試座標。

快速指令：macOS ⌘ + K ／ Windows Ctrl + K

09 · 路線資料

匯入 GPX 或 JSON Waypoints

已有既定軌跡時，可以直接匯入 ArcWayfarer，不需要重新在地圖逐點建立。

GPX

適合 GPS、運動與地圖工具匯出的軌跡。匯入後先確認起點、終點與航點順序再執行。

JSON Waypoints

適合自建固定測試座標集合或從其他工具搬移資料，可搭配多點與循環路線使用。

10 · MOBILE REMOTE

用手機遙控 ArcWayfarer

1

桌面版開啟 Mobile Remote

ArcWayfarer 會產生配對 QR Code。

2

手機掃描 QR Code

不需要另外下載手機 App，直接由瀏覽器開啟控制頁。

3

開始無線控制

建議手機與電腦連接同一個 Wi-Fi；公司、學校或公共網路可能禁止裝置互通。

11 · MULTI-DEVICE

同時管理多部 iPhone

ArcWayfarer 支援多裝置管理。切換裝置後，每次執行 Teleport、Navigate、Joystick 或路線模擬前，請先確認目前控制的 iPhone 是否正確。

12 · 結束模擬

恢復真實 GPS 位置

不再需要模擬位置時，使用 ArcWayfarer 的還原／Restore Location 功能停止目前的 Developer Location Simulation。

不一定會瞬間跳回真實位置。停止模擬後，iPhone 需要重新取得 GPS、Wi-Fi、基地台與其他 Location Services 資訊，實際重新校準可能需要約 30 秒到 2 分鐘。

若 Apple Maps 暫時仍顯示舊位置，保持定位服務開啟並稍等，再重新開啟使用定位的 App。

13 · 第三方 APP

遊戲與 App 相容性

ArcWayfarer 修改的是 iPhone Developer Location Simulation。不同 App 可以自行加入額外定位驗證，因此「系統位置已成功修改」不代表所有 App 都一定接受。

Pikmin Bloom

目前可用於 ArcWayfarer 的系統 GPS 模擬情境。但遊戲廠商可能隨版本調整定位驗證方式，因此未來版本相容性不作永久保證。

Pokémon GO

目前不宣稱支援。現行版本可能偵測 Developer Location Simulation 並顯示「Failed to detect location. (12)」／Error 12。ArcWayfarer 不提供 Error 12 bypass、修改版 IPA 或遊戲客戶端。

14 · TROUBLESHOOTING

常見問題與疑難排解

ArcWayfarer 找不到我的 iPhone

確認 iPhone 已解鎖、USB 線支援資料傳輸、已選擇「信任這部電腦」。重新插拔並重啟 ArcWayfarer。Windows 另外確認 iTunes 或 Apple Mobile Device Support。

已經按過「信任」，為什麼還是找不到？

「信任」只代表 pairing 已完成。裝置偵測仍可能受 USB 通訊、Apple Device Driver、Developer Services、RemoteXPC 或系統權限影響。請允許 ArcWayfarer 啟動時要求的權限並重新連線。

為什麼 ArcWayfarer 啟動要系統權限？

ArcWayfarer 需要建立與 iPhone Developer Services 的通訊環境，底層包含 pymobiledevice3 相關服務。一般使用者只需要接受系統授權，不需要自行執行指令。

Developer Mode 找不到

先用 USB 連接 iPhone、完成信任，再使用 ArcWayfarer 左上角的 Developer Mode 協助功能。之後回到「設定 → 隱私權與安全性」重新查看。

第一次 Teleport 為什麼比較久？

第一次可能正在準備 Developer Disk Image、Developer Services 或 RemoteXPC 通道。流程由 ArcWayfarer 自動完成，不需要安裝 Xcode。

需要安裝 Xcode、Python 或 pymobiledevice3 嗎？

不需要。ArcWayfarer 已封裝成完整 App，這些是內部實作所使用的技術元件。

定位成功，但某個 App 的位置沒有變

先用 Apple Maps 驗證。如果 Apple Maps 已顯示模擬位置，但特定 App 沒有改變，該 App 可能有定位快取或自己的模擬位置偵測機制。

按 Restore 後為什麼還停在模擬位置？

iPhone 重新取得真實位置可能需要約 30 秒到 2 分鐘。稍等後重新開啟地圖 App，並確認系統定位服務仍開啟。

手機遙控掃 QR Code 後連不上

確認手機和電腦位於可互相連線的網路，重新產生 QR Code，並檢查電腦防火牆或 Wi-Fi 是否啟用 Client Isolation。

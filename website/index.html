常見問題

先排除最常遇到的狀況。

使用 ArcWayfarer 需要越獄（Jailbreak）或破解 iPhone 嗎？

完全不需要。ArcWayfarer 採用 Apple 官方標準的開發者除錯服務協議（Developer Disk Image / RemoteXPC），不修改 iOS 系統底層，保持裝置原廠安全性。

是否支援最新版本的 iOS 17 與 iOS 18？

支援。ArcWayfarer 內建自動化 RemoteXPC 通道處理技術，連接後會自動建立安全通訊與位置模擬通道。

Windows 使用者一定要安裝 iTunes 嗎？

是。Windows 需安裝 iTunes 或 Apple Mobile Device Support，才能透過 USB 正確辨識和連接 iPhone。

第一次設定位置為什麼需要等待？

ArcWayfarer 首次操作時可能需要下載並掛載 Apple 開發者服務所需的 Developer Disk Image。請保持網路與 USB 連線，完成後後續操作會立即生效。

手機端無線遙控功能如何運作？需要額外下載手機 App 嗎？

不需要下載額外 App。只需在桌面端點擊「手機遙控」產生 QR Code，用手機相機掃描即可在瀏覽器開啟 Web 搖桿介面，即時無線控制移動方向與速度。

可以同時連接並控制多台 iPhone 嗎？

支援。ArcWayfarer 最多可同時連接與辨識 3 台 iOS 裝置。你可以在介面頂部隨時切換目標設備，分別進行瞬移、導航或路線模擬。

macOS 或 Windows 顯示安全性警告怎麼辦？

macOS 可在應用程式中對 App 按右鍵後選擇「開啟」；Windows SmartScreen 顯示時，選擇「更多資訊」後再按「仍要執行」。

開始前確認

系統與首次使用需求

macOS

  • Apple Silicon 與 Intel 均支援
  • 首次開啟如遭 Gatekeeper 阻擋，請對 App 按右鍵後選擇「開啟」
  • iOS 17+ 第一次啟動通道時，可能會顯示系統授權視窗

Windows

  • Windows 10／11 64-bit
  • 需安裝 iTunes 或 Apple Mobile Device Support
  • iOS 17+ 會要求系統管理員權限以建立通道

你的 iPhone

  • 以 USB 傳輸線連接並解鎖
  • 選擇「信任這部電腦」
  • 首次設定位置時，可能需等待 Developer Disk Image 下載完成

常見問題

先排除最常遇到的狀況。

ArcWayfarer 支援哪些電腦與 iPhone？

支援 macOS（Apple Silicon 或 Intel）及 Windows 10／11 64-bit。iPhone 需以 USB 連接、解鎖並信任電腦。

Windows 使用者一定要安裝 iTunes 嗎？

是。Windows 需安裝 iTunes 或 Apple Mobile Device Support，才能透過 USB 正確辨識和連接 iPhone。

第一次設定位置為什麼需要等待？

ArcWayfarer 首次操作時可能需要下載並掛載 Apple 開發者服務所需的 Developer Disk Image。請保持網路與 USB 連線，完成後後續操作會更快。

macOS 或 Windows 顯示安全性警告怎麼辦？

macOS 可在應用程式中對 App 按右鍵後選擇「開啟」；Windows SmartScreen 顯示時，選擇「更多資訊」後再按「仍要執行」。

這個工具適合哪些情境？

請僅在你擁有或獲得授權的裝置與測試情境中使用，例如位置相關 App 的 QA、路線模擬和研究用途。

## 本次更新

### ArcWayfarer v0.1.20：同時使用多支 iPhone 更穩定，找地點後也能直接瞬移

ArcWayfarer v0.1.20 改善 macOS 與 Windows 上的多裝置 iPhone／iPad GPS 定位模擬。現在，即使 A 手機正在跑路線，你仍可接上或設定 B 手機，不會讓 A 的任務突然停止；搜尋地址、地標或店家後，也能直接選擇一支空閒手機瞬移過去。

### 接上第二支手機，不會停掉第一支

- 當 A 手機正在執行「路線循環」、「多點巡迴」或「種花模式」時，接上、設定或重新搜尋 B 手機，不會再中止 A 的任務。
- 如果拔掉 A 手機的傳輸線後，ArcWayfarer 仍能繼續控制它，A 會保留在「裝置清單」中並顯示「背景控制中」，不會明明還在跑卻從清單消失。
- 正在執行任務的手機不能被停用或拿去執行另一個瞬移，避免操作其他手機時誤停目前的路線。

### 路線畫面不再突然歸零或關閉

- 修正路線跑到一半時，操作面板突然顯示 100%、整條路線消失的問題。重新整理後會恢復原本的點位、速度、移動方式、跳點設定與目前進度。
- 當你正在替 A 手機開啟「路徑收藏」挑選路線時，即使 ArcWayfarer 又找到 B 手機，A 的路徑收藏視窗也不會被關閉。
- 只有在 ArcWayfarer 再次確認找不到 A 手機後，才會關閉 A 的操作畫面；單純找到另一支手機不會影響它。

### 搜尋地址或地標後，可直接瞬移

- 點地圖左側的放大鏡開啟「搜尋地點」，輸入地址、地標、店家或景點名稱後，搜尋到的每個地點右側現在都有藍色瞬移按鈕。
- 先在「搜尋地點」標題旁的「瞬移裝置」選單選擇手機，再按地點右側的藍色按鈕，就會把該手機直接瞬移到那個地點。
- 如果只點地點名稱或地址，ArcWayfarer 會把座標帶回目前的操作面板，讓你先在地圖上確認，不會立即瞬移手機。

### 從「我的最愛」瞬移前，也能選擇手機

- 「我的最愛」上方新增「瞬移裝置」選單，不必先切換右上角目前操作的手機，也能指定哪一支手機要瞬移到收藏地點。
- 選單只會顯示連線正常而且目前沒有執行任務的手機。例如 A 正在跑種花、B 與 C 空閒時，選單只會顯示 B 和 C。
- 如果所有手機都在執行任務，選單會顯示「目前沒有空閒裝置」，不會誤把正在跑路線的手機移走。
- 修正「我的最愛」中裝置選單下方出現大片空白的問題，收藏地點現在會直接接在選單下方顯示。

## What's new

### ArcWayfarer v0.1.20: more reliable multi-device control and direct teleporting from place search

ArcWayfarer v0.1.20 improves multi-device iPhone and iPad GPS simulation on macOS and Windows. If phone A is already following a route, you can connect or set up phone B without stopping A. You can also search for an address, landmark, business, or attraction and teleport an idle phone there directly.

### Connecting a second phone no longer stops the first

- If phone A is running Route Loop, Multi-stop, or Flower mode, connecting, setting up, or rediscovering phone B no longer stops A's task.
- If ArcWayfarer can still control phone A after its cable is unplugged, A remains in Device Manager with a Background control badge instead of disappearing while its route is still running.
- A phone with an active task cannot be disabled or selected for another teleport, helping prevent changes to one phone from interrupting another.

### Route screens no longer reset or close unexpectedly

- Fixed an issue where an active route could suddenly show 100% while the entire route disappeared. ArcWayfarer now restores its waypoints, speed, movement settings, jump configuration, and current progress after a refresh.
- If you are choosing a saved route for phone A, discovering phone B no longer closes A's route Favorites window.
- ArcWayfarer closes A's controls only after confirming that A can no longer be found. Simply discovering another phone does not affect it.

### Teleport directly after searching for an address or landmark

- Open Search from the magnifying-glass button on the left side of the map, then enter an address, landmark, business, or attraction. Each matching place now has a blue teleport button on its right.
- Choose a phone from the Teleport device selector beside the Search title, then press a place's blue button to teleport that phone directly to the selected location.
- Selecting the place name or address still sends its coordinates to the current control panel so you can review it on the map first; it does not immediately teleport the phone.

### Choose a phone before teleporting from Favorites

- Favorites now has a Teleport device selector. You can choose which phone to send to a saved place without first switching the phone selected in the top-right corner.
- Only connected, ready, and idle phones appear. For example, if A is running Flower mode while B and C are idle, the selector shows only B and C.
- If every phone is busy, the selector displays No idle device available instead of moving a phone that is already following a route.
- Fixed the large blank area below the device selector in Favorites so saved places now begin immediately below it.

## 本次更新

- 修正桌面版地圖無法載入的問題：部分環境會被 OpenStreetMap 圖磚服務拒絕，畫面顯示「403 Access blocked」。現在桌面版會透過 ArcWayfarer 本機服務安全取得圖磚，地圖可正常顯示。

## What's new

- Fixed map loading in the desktop app. In some environments OpenStreetMap rejected tile requests with a “403 Access blocked” response. ArcWayfarer now retrieves desktop map tiles through its local service so maps load normally.

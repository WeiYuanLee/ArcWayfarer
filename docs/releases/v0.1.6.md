## 本次更新

v0.1.6 是一次介面與操作流程的大型更新：整個控制台更一致、更容易閱讀，也更適合長時間管理多台裝置。

- 新增淺色、深色與跟隨系統外觀。右上角外觀按鈕可快速切換，所有主要面板、按鈕與對話框都會跟著調整。
- 地圖右側新增地址搜尋。可搜尋地名、地標或地址，結果會顯示名稱、分類、地址與座標；歷史記錄、我的最愛、搜尋與縮放工具的排列也更清楚。
- 改善頂部控制列：裝置狀態更容易辨識、重新掃描與更新提示更清楚，並修正淺色模式下快捷指令與更新視窗的顯示。
- 所有移動模式的設定面板重新整理：瞬移、導航、路線循環、多點巡迴、隨機漫遊與搖桿現在有一致的按鈕、輸入欄位、狀態與操作區。
- 改善瞬移與導航：瞬移可在一般瞬移與拉金盆間切換；導航改用「起點／終點」，執行中會顯示更精簡的路線進度與剩餘時間。
- 改善路線規劃：路線循環與多點巡迴的點位更容易編輯、排序與刪除；新增點位會自動帶到畫面中。路線循環新增「全清點位」，多點巡迴也提供更大的貼上座標編輯區。
- 停留與漫遊設定更清楚：每站暫停會明確顯示隨機停留的最短／最長秒數；隨機漫遊則簡化為中心點與以公尺計算的半徑設定。
- 修正控制面板無法收合的問題，並改善淺色模式下部分邊框、對齊與按鈕的可讀性。

## What's new

v0.1.6 is a major interface and workflow update. The console is now more consistent, easier to scan, and better suited to managing devices over time.

- Added light, dark, and system appearance modes. Use the top-right appearance button to cycle between them; main panels, buttons, and dialogs now follow the selected appearance.
- Added place search to the map action rail. Search for places, landmarks, or addresses and see each result's name, category, address, and coordinates. History, Favorites, Search, and zoom tools are also arranged more clearly.
- Improved the top control bar with clearer device status, rescan controls, and update feedback. Command shortcuts and the update dialog now display correctly in light mode.
- Refreshed every movement settings panel: Teleport, Navigate, Route Loop, Multi-stop, Random Walk, and Joystick now share consistent inputs, buttons, status feedback, and action areas.
- Improved Teleport and Navigate. Switch between standard Teleport and Gold Ditto, use clear Start/Destination fields, and view a more compact route progress and ETA display while navigating.
- Improved route planning. Route Loop and Multi-stop waypoints are easier to edit, reorder, and remove; new waypoints are brought into view automatically. Route Loop adds Clear All, while Multi-stop provides a larger editor for pasting coordinates.
- Clarified dwell and roaming settings. Per-stop pauses now clearly show randomized minimum and maximum seconds; Random Walk is simplified to a center point and meter-based radius.
- Fixed an issue that prevented the map control panel from collapsing, and improved light-mode borders, alignment, and button readability.

## 本次更新

### ArcWayfarer v0.1.16：修正白畫面，讓 iPhone GPS 定位模擬更穩定

ArcWayfarer v0.1.16 改善 macOS 與 Windows 上的 iPhone／iPad GPS 定位模擬體驗，修正連接裝置或將視窗縮到最小後，操作介面可能卡住、持續佔用系統資源或顯示白畫面的問題。若介面仍意外失去回應，現在也能直接重新載入畫面，不必自行尋找或清除快取。

### 操作介面不再因裝置更新而卡住

- 修正連接一台或多台 iOS 裝置後，操作面板可能反覆更新，造成 ArcWayfarer 卡頓、無法點擊或顯示白畫面的問題。
- 降低異常更新造成的 CPU 與記憶體占用，讓裝置切換、定位操作與地圖顯示維持順暢。
- 改善視窗從最小化恢復時的穩定性，避免已經卡住的介面只顯示空白內容。

### 白畫面時也能安全恢復

- ArcWayfarer 現在會偵測操作介面是否失去回應；若視窗恢復後仍無法正常更新，會顯示系統提示供使用者重新載入介面。
- 重新載入只會重建操作畫面，不會停止後端正在執行的裝置任務；畫面恢復後會重新同步目前進度。
- 若操作介面意外結束，也會提供相同的恢復選項，不再需要強制結束整個 App 或手動清除快取。

### 草稿只保留最近的操作

- 多點巡迴與種花模式草稿現在保留 30 分鐘，方便短時間內關閉面板或重新載入後繼續設定。
- 超過 30 分鐘的草稿會自動移除，避免舊座標與過期設定在之後重新出現。

### 地圖路線顯示更省資源

- 降低即時路線、定位標記與地圖投影更新的負擔，長時間使用時畫面更穩定。
- 路線尚未開始執行時不再播放移動箭頭；只有任務實際運行時才顯示行進方向，避免預覽畫面持續消耗資源。
- 地圖控制按鈕的外觀與滑鼠互動保持一致，縮放與其他地圖工具更容易辨識。

### 執行中的裝置不會誤切換模組

- 多點巡迴、路線循環或其他定位任務執行期間，該裝置會暫停切換其他操作模組。
- 執行期間也會暫停新增或修改座標，避免路線設定在任務進行中被意外改動。
- 多裝置仍可分別操作；切換到另一台未執行任務的裝置後，仍可正常選擇模組與設定座標。

## What's new

### ArcWayfarer v0.1.16: fewer blank screens and more reliable iPhone GPS simulation

ArcWayfarer v0.1.16 improves iPhone and iPad GPS simulation on macOS and Windows. It fixes an issue that could leave the interface frozen, consuming system resources, or showing a blank screen after connecting devices or restoring a minimized window. If the interface ever becomes unresponsive, ArcWayfarer can now reload it directly without asking the user to find or clear cached files.

### A responsive interface after device updates

- Fixed repeated panel updates that could make ArcWayfarer slow, unclickable, or blank after one or more iOS devices connected.
- Reduced abnormal CPU and memory usage so device switching, location controls, and the map remain responsive.
- Improved reliability when restoring a minimized window, preventing an already stalled interface from returning as an empty screen.

### Safe recovery from a blank or unresponsive screen

- ArcWayfarer now detects when its interface stops responding. If the window still cannot update after being restored, a system prompt offers to reload the interface.
- Reloading rebuilds only the interface. Device tasks running in the background continue and their current progress is synchronized afterward.
- The same recovery option is available if the interface process exits unexpectedly, so users no longer need to force-quit the entire app or clear caches manually.

### Only recent drafts are restored

- Multi-stop and Flower mode drafts are now retained for 30 minutes, allowing recent setup to survive a closed panel or interface reload.
- Drafts older than 30 minutes are removed automatically, preventing stale coordinates and settings from reappearing later.

### Smoother map route display with lower background work

- Reduced the amount of live route, marker, and map projection work so the interface stays steadier during longer sessions.
- Moving arrows no longer play before a route starts. Direction arrows appear only while a task is actually running, avoiding unnecessary work during route preview.
- Map control buttons now share consistent visual and hover behavior, making zoom and other map tools easier to recognize.

### Prevent accidental module changes during an active task

- While Multi-stop, Route Loop, or another location task is running, the selected device is locked to its current module.
- Adding or editing coordinates is also paused during the task, preventing an active route from being changed accidentally.
- Multi-device workflows remain independent: switch to another device with no running task to choose a module and set coordinates normally.

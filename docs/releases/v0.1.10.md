## 本次更新

### WebGL 地圖顯示改善

- 修正高效能模式中定位圖釘與裝置實際位置圓點可能上下錯位的問題，兩者現在會準確對齊相同座標。
- 調整導航、路線循環與多點巡迴的顯示層級，路線不再遮住起點、終點與途經點，行進位置更容易辨識。
- 修正多點巡迴的方向箭頭可能偏離路線的問題，動畫箭頭現在會沿著路線置中顯示。
- 修正高效能模式中隨機漫遊未顯示活動範圍的問題，現在會清楚標示設定半徑的圓形區域。
- 改善高效能地圖的啟動與模式切換穩定性，降低地圖資源偶發載入失敗的情況。
- 修正從高效能模式切回標準模式後，地圖點位與已規劃路線可能消失的問題；往返切換時會完整保留目前內容。

### 導航路線預覽

- 輸入導航起點與終點後，標準模式與高效能模式都會在開始前自動規劃並畫出實際道路路線，方便先確認行進方向。
- 拖曳起點或終點時只移動地圖標記，放開後才重新規劃路線，減少不必要的網路與電腦資源消耗。
- 切換走路、騎車或開車模式時會自動更新路線；預估距離也會在規劃完成後改用實際道路長度。
- 路線暫時無法取得時會提供重新規劃選項，不會用直線冒充道路，也不會在預覽期間改變手機定位。

### 我的最愛匯出與匯入

- 現在可依分組選擇要匯出的我的最愛，建立可在其他 ArcWayfarer 使用的 JSON 備份檔。
- 匯入檔案後會先顯示新增、略過重複點位與即將建立的分組數量，確認後才會寫入。
- 相同或相距 5 公尺內的點位不會重複建立；會保留目前裝置上的名稱、分組與備忘內容。

### 裝置連線與定位穩定性

- 新增 Wi-Fi 裝置探索開關；啟用後會定期更新已透過 Wi-Fi 配對的 iPhone，關閉時僅搜尋 USB 裝置，並優先使用 USB 連線。
- 裝置掃描改為共用同一次搜尋作業，暫時掃描失敗時會保留上次成功找到的裝置；若 USB 掃描失敗且未找到裝置，可直接複製診斷資訊回報問題。
- 改善停止導航、瞬移與還原真實定位之間的協調，避免已取消的路線繼續寫入位置；還原指令的送達可靠性也一併提升。
- 更新 iOS 裝置連線元件，改善目前 iOS 版本的安全通道相容性。

### 手機遠端遙控

- 手機掃碼遙控的標準與高效能地圖現在都能安全載入；地圖 tile 請求會使用配對連線驗證。
- 手機地圖的控制列改用與桌面版一致的設計系統，同時保留適合觸控操作的底部控制面板。

## What's new

### WebGL map display improvements

- Fixed vertical misalignment between the location pin and the device's live-position dot in High Performance mode. Both now align precisely at the same coordinate.
- Improved visual stacking for navigation, route loops, and multi-stop trips so routes no longer cover start, end, or waypoint markers.
- Fixed direction arrows appearing offset from multi-stop routes. Animated arrows now stay centered on the route.
- Fixed the missing random-walk boundary in High Performance mode. The configured circular area is now clearly displayed.
- Improved High Performance map startup and mode-switching reliability, reducing intermittent map-resource loading failures.
- Fixed map markers and planned routes sometimes disappearing after switching from High Performance back to Standard mode. Current map content is now preserved in both directions.

### Navigation route preview

- After entering a start and destination, both Standard and High Performance modes now plan and draw the actual road route before navigation begins.
- Dragging the start or destination only moves the marker; the route is recalculated after release, reducing unnecessary network and computer-resource usage.
- Routes update automatically when switching between walking, cycling, and driving. Estimated distance uses the planned road distance once available.
- If a route is temporarily unavailable, the app offers a retry instead of drawing a misleading straight line, and previewing never changes the phone's location.

### Favorite export and import

- Favorites can now be exported by selected group into a portable JSON backup for use with another ArcWayfarer installation.
- Before importing, the app previews additions, skipped duplicates, and groups that will be created. Nothing is written until confirmation.
- Locations that are the same or within 5 meters are not duplicated; the current device's name, group, and notes are retained.

### Device connection and location stability

- Added a Wi-Fi device-discovery switch. When enabled, ArcWayfarer periodically refreshes iPhones paired over Wi-Fi; when disabled, it searches USB devices only and prefers USB when both are available.
- Device scans now share a single discovery operation and retain the last successful device list during a temporary scan failure. If USB discovery fails with no devices found, a diagnostic report can be copied for support.
- Improved coordination between stopping navigation, teleporting, and restoring the real location, preventing a canceled route from writing a later position. Delivery reliability for restore commands has also been improved.
- Updated the iOS device-connection component for better secure-tunnel compatibility with current iOS versions.

### Mobile remote control

- Both Standard and High Performance maps now load securely in the QR-paired mobile remote; map-tile requests use the paired-session authorization.
- The mobile map control rail now follows the desktop design system while retaining its touch-friendly bottom control sheet.

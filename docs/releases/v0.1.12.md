## 本次更新

### 種花模式剩餘時間

- 多點巡迴的種花模式新增剩餘時間倒數。有限行程會顯示本次行程的預估剩餘時間；持續循環則顯示目前一圈的剩餘時間。
- 倒數會納入花朵半徑、繞圈數、實際花圈幾何、進場與花點間移動、抵達前／完成後等待、回到起點設定，以及自訂移動速度。
- 等待期間會平順地每秒更新；暫停時倒數會維持不動。道路導航距離仍依實際路由服務結果而屬預估值。

### 裝置管理與安全遮蔽

- 新增右上角「裝置管理」，可管理本機的裝置遮蔽名單；已遮蔽裝置持續接受 USB／Wi‑Fi 掃描，但不會出現在操作列、地圖或裝置控制中。
- 裝置管理支援依 UDID 儲存自訂名稱；右上分頁會直接使用自訂名稱，並可隨時清空以恢復系統名稱。
- 同時最多可使用三台裝置。超出的設備會顯示為等待可用名額；必須先遮蔽一台可使用裝置，才可恢復其他設備供操作。
- 遮蔽待命設備時，程式會先還原真實定位，成功後才將設備移至遮蔽名單；若還原失敗，設備會維持可見。執行中或暫停中的設備必須先停止任務才可遮蔽。

### 貼上座標容錯改善

- 多點巡迴的「貼上座標」現在會掃描整段內容中的所有有效座標，不再限制每行只能有一組；即使 OCR 將多組座標擠在同一行也能正確匯入。
- 支援 OCR 常見的全形數字與標點。夾雜的中文字會在解析前自動排除，不會造成匯入失敗。
- 超出經緯度範圍的內容會略過，其他有效座標仍可匯入。

### 最愛匯入相容格式

- 「我的最愛」匯入現在支援相容的純陣列 JSON 格式；只要每筆包含名稱與有效經緯度，即可先預覽再匯入。
- 來源的 ID、畫框樣式與其他非地點資料不會帶入；建立時間會自動由毫秒轉換，並依原始檔案順序排列。
- 匯入仍會保留 5 公尺內去重機制，且會清楚標示已使用相容格式轉換。

### 手機遙控任務狀態

- 手機遙控頁面現在會在連線時取得目前正在執行的任務類型與路徑；即使任務從桌面端啟動或切換操作模式，地圖仍會保留活動路徑。
- 修正切換至多點巡迴或路線循環時可能造成頁面空白的重繪迴圈。

## What's new

### Remaining time for Flower mode

- Multi-stop Flower mode now shows a remaining-time countdown. Finite itineraries display the estimated time remaining for the trip, while continuous loops display the time remaining in the current circuit.
- The estimate includes flower radius, circle count, generated flower geometry, approach and inter-flower travel, pre/post waits, return-to-start behavior, and custom speed.
- The countdown updates smoothly every second during waits and holds while paused. Road-navigation legs remain estimates because their final distance depends on the routing service.

### Device management and safe hiding

- Added Device Manager in the top bar for a local hidden-device list. Hidden devices continue to be discovered over USB/Wi-Fi but never appear in the operational tabs, map, or controls.
- Device Manager supports UDID-bound custom names. Tabs use the custom name directly, and clearing it restores the system name at any time.
- Up to three devices may be used at once. Extra discoveries wait for an available slot; hide a usable device before restoring another one for operation.
- Hiding an idle device first restores its real location and only then hides it. A failed restore leaves it visible, and running or paused devices must stop their task before they can be hidden.

### More resilient pasted coordinates

- Multi-stop's Paste coordinates now scans the entire input for every valid coordinate pair instead of limiting input to one pair per line, so coordinates collapsed onto one line by OCR import correctly.
- Full-width digits and punctuation commonly produced by OCR are supported. Chinese text is removed before parsing, so it cannot cause an import failure.
- Out-of-range coordinate pairs are skipped while other valid coordinates still import.

### Compatible favorites imports

- Favorites import now supports compatible plain-array JSON files. Entries containing a name and valid latitude/longitude can be previewed before import.
- Source IDs, frame styles, and other non-location metadata are not carried over; millisecond timestamps are converted automatically and entries retain their source order.
- The existing 5-meter duplicate protection remains in effect, and the preview clearly indicates when a compatible format was converted.

### Mobile remote task status

- The mobile remote now receives the current task type and route when it connects. Active paths remain visible on the map even when a task was started from desktop or the mobile control mode changes.
- Fixed a rendering loop that could leave the mobile page blank when switching to Multi-stop or Route loop.

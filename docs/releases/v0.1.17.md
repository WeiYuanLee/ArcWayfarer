## 本次更新

### ArcWayfarer v0.1.17：更快規劃多點與循環路線，macOS 安裝更直覺

ArcWayfarer v0.1.17 改善 macOS 與 Windows 上的 iPhone／iPad GPS 定位模擬體驗。「多點巡迴」現在可以在出發前自動整理更精簡的點位順序，「路線循環」也能一次貼上多組座標。本次更新也讓常用抽屜開啟更可靠、數值設定的輸入提示更友善，並為 macOS 安裝畫面加入更清楚的拖放與首次開啟指引。

### 一鍵優化多點巡迴順序

- 「多點巡迴」的基礎模式與「種花模式」現在提供「優化路線順序」，可在開始執行前自動重新排列點位，減少不必要的來回折返。
- 優化時會保留第 1 個點位，並依預估直線距離整理其餘座標；「種花模式」也會配合停在終點、回到起點或持續循環的設定評估順序。
- 完成後會顯示預估縮短的距離與比例，並可立即復原原本順序。開始執行、修改點位或切換模式後，舊的復原操作會自動失效，避免套用到不同路線。
- 優化只會在路線尚未執行時提供；執行中或暫停中不會變更目前行程。瞬移前往模式仍可整理點位順序，但不會改變每站的跳躍等待時間。
- 單次最多可優化 500 個點位；超過時會提示先精簡路線，避免大量座標影響操作流暢度。

### 一次貼上多個路線循環座標

- 「路線循環」的手動路徑點現在提供「貼上座標」，可一次匯入多組經緯度，操作方式與「多點巡迴」一致。
- 即使多組座標被 OCR 擠在同一行，或內容混有全形標點，ArcWayfarer 仍會找出其中可用的座標；超出有效範圍的座標會略過，不影響其他有效點位。
- 套用後，地圖會移至第一個匯入點，方便立即確認路線位置與點位順序。
- 若目前已有路徑點，覆蓋前會先顯示確認提示；取消後會保留原有路線，避免誤刪已完成的規劃。

### 裝置資訊更容易確認

- 將滑鼠移到裝置分頁，或使用鍵盤將焦點移到分頁時，現在可以查看裝置連線資訊與 UDID，辨識多台 iOS 裝置更方便。
- 裝置狀態、目前任務與進度資訊會集中顯示在同一張提示卡中，不必切換畫面逐一確認。

### 常用操作更可靠

- 修正操作記錄、我的最愛與搜尋抽屜首次點擊時可能沒有開啟的問題。在不同抽屜間切換時，前一個內容也不會再重疊在下方。
- 圖案大小、花朵半徑、繞圈數、等待時間與其他數值設定現在會保留輸入內容。輸入中文、全形數字或超出允許範圍時，欄位會顯示紅框與清楚提示，不再立即跳回預設值。
- 數值內容修正前會暫停開始路線或移動任務，避免畫面顯示輸入錯誤時仍使用上一個數值。

### macOS 安裝步驟更清楚

- macOS 的 DMG 安裝畫面現在會並列顯示 ArcWayfarer 與「應用程式」資料夾捷徑，更容易看出要將 App 拖入「應用程式」完成安裝。
- 若首次開啟時 macOS 顯示「無法驗證開發者」，安裝畫面也會提示從「應用程式」中按住 Control 鍵開啟，減少卡在系統警告的情況。
- 安裝畫面加入 ArcWayfarer 專屬背景與更清楚的圖示配置，Intel 與 Apple Silicon 版本皆維持相同的安裝方式。

## What's new

### ArcWayfarer v0.1.17: faster Multi-stop and Route Loop planning with clearer macOS installation

ArcWayfarer v0.1.17 improves iPhone and iPad GPS simulation on macOS and Windows. Multi-stop can now organize waypoints into a more efficient order before a route begins, and Route Loop accepts multiple pasted coordinates at once. This update also makes commonly used drawers more reliable, provides friendlier feedback for numeric settings, and adds clearer drag-to-install and first-launch guidance to the macOS installer.

### Optimize a Multi-stop route in one click

- Basic mode and Flower mode in Multi-stop now include Optimize Route, which reorganizes waypoints before a route starts to reduce unnecessary backtracking.
- Waypoint 1 stays fixed while the remaining coordinates are arranged by estimated straight-line distance. Flower mode also accounts for whether the route stops at the end, returns to the start, or keeps looping.
- After optimization, ArcWayfarer shows the estimated distance and percentage saved and lets you immediately restore the previous order. The old Undo action expires when the route starts, a waypoint changes, or the mode changes, preventing it from being applied to a different route.
- Optimization is available only before a route starts. It never changes a running or paused route. Jump mode can still organize waypoint order, but its per-stop wait time remains unchanged.
- Up to 500 waypoints can be optimized at once. Larger routes display a prompt to simplify the waypoint list first, keeping the interface responsive.

### Paste multiple Route Loop coordinates at once

- Manual Waypoints in Route Loop now includes Paste Coordinates, with the same workflow available in Multi-stop.
- ArcWayfarer can find usable coordinates even when OCR places several pairs on one line or introduces full-width punctuation. Out-of-range coordinates are skipped without discarding the other valid points.
- After applying the coordinates, the map moves to the first imported point so you can immediately review the route location and waypoint order.
- If the route already contains waypoints, ArcWayfarer asks for confirmation before replacing them. Canceling keeps the existing route unchanged.

### Easier device identification

- Hover over a device tab, or focus it with the keyboard, to view connection details and the device UDID, making multiple iOS devices easier to tell apart.
- Device status, the current task, and progress information are presented together in the same information card.

### More reliable everyday controls

- Fixed History, Favorites, and Search drawers sometimes failing to open on the first click. Switching between these drawers also no longer leaves the previous drawer layered underneath.
- Pattern size, Flower radius, circle count, wait times, and other numeric settings now preserve what you type. Chinese text, full-width digits, and out-of-range values display a clear red validation message instead of immediately reverting to a default value.
- Route or movement tasks remain unavailable until an invalid numeric entry is corrected, preventing ArcWayfarer from silently using the previous value.

### Clearer macOS installation

- The macOS DMG now places ArcWayfarer beside an Applications folder shortcut, making the drag-to-install step easier to understand.
- If macOS shows an “unable to verify the developer” message on first launch, the installer background now explains how to Control-click ArcWayfarer in Applications and open it.
- A branded background and clearer icon layout provide the same guided installation experience for both Intel and Apple Silicon downloads.

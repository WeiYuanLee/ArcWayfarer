## 本次更新

### ArcWayfarer v0.1.18：加入皮克敏明信片與純點地圖，Windows Wireless Direct 正式支援

ArcWayfarer v0.1.18 在「我的最愛」中加入皮克敏明信片與純點地圖，讓你尋找地點、預覽位置、收藏座標，再將連線中的 iPhone 移動到想去的地點。同時，Windows Wireless Direct 也在本次更新中正式獲得支援，讓 iPhone GPS 定位模擬更自由。

### 從「我的最愛」探索明信片與純點

- 「我的最愛」新增「明信片」與「純點」分頁，可直接瀏覽由[皮克敏純點明信片地圖](https://pikmin.talllkai.com)提供的地點資料。
- 明信片可依名稱或描述搜尋，並依國家及明信片種類篩選；純點可依飾品種類篩選。
- 選擇純點飾品種類後，地圖會隨機前往其中一個符合條件的地點，並顯示附近相同種類的純點，方便從尚未探索的區域開始尋找。
- 切換到純點時會自動調整到適合查看座標的縮放比例；若之後將地圖縮得太遠，ArcWayfarer 會提示需要放大地圖。
- 明信片縮圖加大，並加入清楚的種類標籤與放大提示；點擊照片即可開啟大圖預覽。
- 國家與飾品種類改為直接從選單挑選，避免輸入文字後找不到其他選項。
- 明信片的「重新整理」現在會真正同步來源網站；來源已刪除且圖片失效的舊項目也會從本機清單移除。

### 預覽、收藏與定位更順手

- 點擊明信片或純點卡片即可在地圖上預覽該位置；按下「定位」才會將目前連線的裝置移到該座標。
- 點擊「收藏」可將地點儲存到「我的最愛」。來自資料來源的地點會依來源識別，因此同一座標的不同明信片也能分別收藏。
- 明信片與純點收藏只保存在目前的 ArcWayfarer 中，不會加入匯入或匯出檔案；原有「我的最愛」匯入與匯出功能維持不變。
- 打開「我的最愛」時，地圖不再變暗或停止操作，目前使用中的功能列也會自動收起，方便同時查看清單與移動地圖。
- 標準地圖與高效能地圖現在都能正確顯示純點；高效能地圖中標記集中在左上角、拖曳時短暫出現後消失的問題已修正。

### 收藏管理更清楚

- 編輯收藏時，群組欄位改為從現有群組或「未分組」中選擇，避免誤建不存在的群組。
- 收藏排序與「新增群組」整合在同一列，減少控制項占用的空間，清單一次可顯示更多內容。
- 一般收藏項目也可直接使用「定位」，將目前連線的裝置移到指定座標。
- ArcWayfarer 會在啟動時檢查皮克敏資料是否需要更新；距離上次成功更新超過 7 天時會自動同步，若更新失敗，則會在下次啟動時再次嘗試。

### 多點巡迴路線更容易分享

- 多點巡迴的「匯出」選單可下載包含完整路線設定的 JSON 檔案，或依目前順序將所有座標複製到剪貼簿；複製的內容也能直接貼回「貼上座標」。

### Windows 也能使用 Wireless Direct

- Windows Wireless Direct 已獲得實機測試成功回報，本次更新正式公告支援。
- 首次設定仍需以 USB 連接 iPhone，完成信任與必要的無線授權；之後可透過 Wireless Direct 建立無線連線。
- USB 連線方式仍可使用，方便依使用環境選擇有線或無線連線。

## What's new

### ArcWayfarer v0.1.18: explore Pikmin postcards and Pure Spots, with official Windows Wireless Direct support

ArcWayfarer v0.1.18 adds Pikmin postcards and Pure Spots to Favorites. You can find places, preview them on the map, save their coordinates, and move a connected iPhone to the location you choose. This release also adds official Windows Wireless Direct support for more flexible iPhone GPS simulation.

### Explore postcards and Pure Spots from Favorites

- Favorites now includes Postcards and Pure Spots tabs with location data provided by the [Pikmin Pure Spot & Postcard Map](https://pikmin.talllkai.com).
- Search postcards by name or description, then filter them by country and postcard type. Pure Spots can be filtered by decor type.
- Choosing a Pure Spot decor type takes the map to a random matching location and shows nearby Pure Spots of the same type, giving you an easy place to start exploring.
- Opening the Pure Spots tab automatically adjusts the map to a useful zoom level. If you zoom out too far afterward, ArcWayfarer prompts you to zoom in before the locations can be displayed.
- Postcard thumbnails are larger and now include clearer type labels and a zoom indicator. Click a photo to open a larger preview.
- Country and decor filters now use selection-only menus, so all available choices remain easy to find.
- Refresh now syncs postcards with the source website. Stale entries whose source record and image have been removed are also cleared from the local list.

### Smoother previewing, saving, and teleporting

- Click a postcard or Pure Spot card to preview its location on the map. Use Teleport only when you want to move the currently connected device to those coordinates.
- Use Save to add a location to Favorites. Source locations are identified by their original record, so different postcards at the same coordinates can be saved separately.
- Saved postcards and Pure Spots remain local to the current ArcWayfarer installation and are excluded from import and export files. Import and export for existing regular favorites continue to work as before.
- Opening Favorites no longer dims or blocks the map. The active tool bar also collapses automatically, making it easier to browse the list while moving around the map.
- Pure Spots now display correctly on both the standard and high-performance maps. This fixes markers collecting in the top-left corner or appearing only briefly while dragging the high-performance map.

### Clearer Favorites management

- When editing a favorite, choose its group from existing groups or Ungrouped. This prevents accidental entries that do not match an existing group.
- Favorite sorting and New group now share one compact row, leaving more room for the list.
- Regular favorites now also include a direct Teleport action for moving the connected device to their saved coordinates.
- ArcWayfarer checks for Pikmin data updates at launch. It automatically syncs when the last successful update is more than seven days old, and retries the next time the app starts if an update fails.

### Easier sharing for multi-stop routes

- The multi-stop Export menu can download a JSON file with the complete route settings or copy every coordinate to the clipboard in its current order. Copied coordinates can also be pasted directly back into Paste coordinates.

### Wireless Direct is now supported on Windows

- Windows Wireless Direct has received a successful real-device test report and is officially announced as supported in this release.
- Initial setup still requires a USB connection to establish trust and complete the required wireless authorization. Subsequent connections can use Wireless Direct.
- USB connections remain available, allowing you to choose a wired or wireless connection for your setup.

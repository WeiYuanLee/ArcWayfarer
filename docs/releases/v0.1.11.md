## 本次更新

### 多點巡迴種花模式

- 多點巡迴新增「種花模式」。可使用一個以上的花朵中心點，設定花朵半徑、繞圈數、抵達前／完成後等待時間與行程終點方式。
- 預設採用穿越花心、由外向內的螺旋軌跡，減少多圈時重複走在同一條圓周上的情況；仍可切換為圓周繞行。
- 地圖會顯示每朵花的範圍、花點順序與目前轉場路段；執行中使用專屬面板顯示花朵進度、階段，並可暫停、跳過目前花朵或停止。
- 基礎多點巡迴與種花模式使用明確的啟動模式，確保基礎巡迴不會誤進入種花執行器。

### 建議領果座標

- 種花模式可依目前花朵中心，隨機產生 25–50 公尺的建議領果位移座標。
- 可在工具內查看位移分布與完整座標清單，一鍵複製分享文字或匯出 GPX waypoint 檔；不會改動種花路線。

### 執行中資訊面板

- 導航、多點巡迴與路線循環在執行時，現在會清楚顯示「執行中」或「已暫停」狀態，以及目前前往的路段。
- 新增進度、剩餘距離、預估時間、即時速度與目前站點資訊，讓執行過程更容易掌握。
- 暫停、繼續與停止控制維持固定且易於辨識；連線重連時會顯示明確提示。
- 剩餘距離會依目前裝置位置與正在行進的路段估算，避免只以站點數判斷進度。

### 地圖顯示改善

- 地圖上的路線與編號不再遮住控制面板的標題和按鈕，操作時能持續看清目前狀態。

### 定位還原可靠性

- 還原真實定位完成後，會同步清除即時位置標記並通知所有已連線的畫面；介面會明確提示真實 GPS 更新可能需要幾秒。
- 多裝置連線時，瞬移面板新增「還原所有裝置」操作，會平行處理各裝置並清楚回報個別失敗，不會因單一裝置問題中斷其餘還原。
- 還原流程會明確發送待命狀態，讓正在執行或暫停的導航、路線循環與搖桿控制都能一致地回到閒置狀態。

## What's new

### Flower mode for multi-stop

- Multi-stop now includes Flower mode. Use one or more flower centres and configure radius, circles, pre/post waits, and how the itinerary ends.
- The default centre-crossing outer-to-inner spiral reduces repeated perimeter passes on multi-circle runs. A perimeter option remains available.
- The map shows every flower range, order, and active transfer. A dedicated in-flight panel shows flower progress and phase, with pause, skip-current-flower, and stop controls.
- Basic multi-stop and Flower mode now use explicit start modes so a basic trip cannot enter the Flower runner by mistake.

### Suggested fruit coordinates

- Flower mode can generate randomly offset suggested fruit coordinates, from 25 to 50 metres from the current flower centres.
- Review the offset distribution and complete coordinate list, copy shareable text, or export GPX waypoints without changing the Flower route.

### Active flight information panel

- Navigation, multi-stop trips, and route loops now clearly show whether they are running or paused, together with the current leg.
- Added progress, estimated remaining distance and time, live speed, and current-stop information for clearer in-flight awareness.
- Pause, resume, and stop controls remain prominent, with a clear notice while the connection is being restored.
- Remaining distance is estimated from the device's live position and the active route leg instead of relying only on stop count.

### Clearer map controls

- Route lines and numbered waypoints no longer cover panel headings or controls, so the current status and actions stay easy to see.

### More reliable location restore

- After restoring real location, ArcWayfarer clears the live-position marker and notifies every connected view. The interface now makes clear that a fresh GPS update can take a few seconds.
- When multiple devices are connected, the Teleport panel offers Restore all devices. Requests run in parallel and report individual failures without interrupting restores for the other devices.
- Restore explicitly publishes the idle state so running or paused navigation, route loops, and joystick control return to a consistent standby state.

## 本次更新

### 地圖體驗

- 新增「地圖模式」切換，可選擇穩定省資源的「標準模式」，或操作更流暢的「高效能模式」。切換時會保留目前查看的位置與縮放比例，並記住你的選擇。
- 改善地圖圖磚的快取與連線效率；再次查看常用區域時載入更快，移動與縮放也更順暢。
- 高效能模式現在完整支援地圖點選、標記拖曳、路線、方向動畫、圓形範圍與右鍵操作，使用方式與標準模式一致。
- 執行導航、路線循環、隨機漫遊或搖桿移動時會鎖定地圖模式，避免途中誤切造成畫面或操作中斷。

### 路線與定位

- 修正高效能模式中，路線循環與多點巡迴在三個以上點位時可能不顯示完整路線的問題。執行中仍會保留全程路線，並清楚標示目前行進路段。
- 修正高效能模式定位圖釘的些微視覺偏移，現在會與標準模式的位置對齊。
- 切換功能模式時會清除上一個模式的暫存點位與路線，避免舊標記殘留在地圖上。
- 改善圓形路線編輯：可直接拖曳產生的點位微調路線，拖曳後會自動轉為手動路線；相關選項在較小視窗中也更容易瀏覽與設定。

### 穩定性與發行

- 改善 macOS 啟動流程：完成必要的管理員授權與連線服務準備後才開啟主畫面，失敗時也會提供更清楚的提示。
- 改善新版 iOS 裝置的連線與封裝後端啟動穩定性。
- 下載頁面會隨新版本同步更新，避免下載到與頁面版本不一致的安裝程式。

## What's new

### Map experience

- Added a map-mode switch. Choose the stable, resource-friendly Standard mode or the smoother High Performance mode. Your current location, zoom level, and preferred mode are preserved when switching.
- Improved map-tile caching and connection reuse. Familiar areas load faster, with smoother panning and zooming.
- High Performance mode now fully supports map picking, draggable markers, routes, animated directions, circular areas, and context-menu actions, matching Standard mode behavior.
- Map-mode switching is locked while navigation, route loops, random walk, or joystick movement is running, preventing accidental interruptions.

### Routes and location

- Fixed incomplete or missing routes in High Performance mode for route loops and multi-stop trips with three or more points. The complete route now remains visible during playback, with the current leg clearly highlighted.
- Fixed the slight visual offset of the location pin in High Performance mode so it aligns with Standard mode.
- Switching control modes now clears temporary points and routes from the previous mode, preventing stale markers from remaining on the map.
- Improved circular-route editing: generated points can be dragged for fine adjustments and automatically become a manual route. Related options are also easier to browse in smaller windows.

### Reliability and releases

- Improved macOS startup. The main window now opens after the required administrator permission and connection service are ready, with clearer guidance when startup fails.
- Improved connection reliability for newer iOS devices and packaged-backend startup.
- The download page now updates together with each release, helping ensure the installer matches the version shown on the page.

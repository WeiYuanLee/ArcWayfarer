## 本次更新

### ArcWayfarer v0.1.19：收藏整套路徑，種花可接續起跑，拉金盆時機自己掌握

ArcWayfarer v0.1.19 讓 macOS 與 Windows 上的 iPhone／iPad GPS 定位模擬更適合重複巡迴與 Pikmin Bloom 操作。你現在可以收藏整套路徑與玩法設定、從中途接續種花，並在拉金盆畫面準備完成後再自行切回真實定位；長距離巡迴也新增極速模式。

### 常跑路線可以直接收藏與載入

- 「路線循環」、「多點巡迴」與「種花模式」新增「路徑收藏」，可開啟內建路徑或儲存自己的路徑。
- 以原本模式載入時，座標、速度、移動方式與相關設定會一起還原；載入其他模式時則只帶入座標，並提醒你重新確認參數。
- 新增 26 條公園盆、森林盆、山丘、體育館、票卷、超市與神社等固定純點路徑，以及 3 個依目前位置產生的附近路線範本。
- 自行收藏的路徑目前保存在這套 ArcWayfarer 中，本版尚未提供跨電腦同步。

### 路線編輯與巡迴更靈活

- 路線循環、多點巡迴與種花模式的點位現在可以直接拖曳排序。
- 種花模式可指定從路線中的任一朵花開始；手動停止後也會記住中斷位置，方便下一次接著跑。
- 路線循環與多點巡迴新增 100–1000 km/h 極速模式，方便快速通過長距離路線或間距較大的點位。

### 拉金盆不再受固定等待時間限制

- 拉金盆改為「飛往金盆 → 開啟畫面 → 拉盆還原」三步驟引導，會清楚提示目前該做的動作。
- 飛抵金盆後會持續停留，直到你確認 Pikmin Bloom 的拉盆畫面已開啟，不會再因固定秒數結束而提早跳回。
- 按下「開始拉盆」時會立即開始還原定位；畫面上的 3 秒倒數是持續拉住的提示，不是等待倒數結束才送出還原指令。
- 原始位置可自動帶入，也能手動輸入或從地圖調整；等待期間仍可隨時取消並恢復真實定位。

### 操作回饋更集中

- 操作成功、警告與錯誤訊息現在統一顯示在右下角，並改用較容易理解的說明，不再讓底層連線訊息直接出現在操作面板中。
- 多裝置環境下，還原定位只會針對實際操作顯示一次結果，避免重複出現相同的成功通知。
- 頂部模式切換列改用精簡圖示，「路徑收藏」則保留文字標籤，讓主要操作更容易辨識並為地圖留出更多空間。

## What's new

### ArcWayfarer v0.1.19: save complete routes, resume Flower mode, and control Gold Ditto timing

ArcWayfarer v0.1.19 makes iPhone and iPad GPS simulation on macOS and Windows better suited to repeat routes and Pikmin Bloom workflows. You can now save complete routes with their settings, resume Flower mode from the middle, and return to real GPS only after the Gold Ditto screen is ready. Turbo mode is also available for long-distance routes.

### Save and reload the routes you use most

- Route Loop, Multi-stop, and Flower mode now include Favorites for opening built-in routes or saving your own.
- Loading a route into its original mode restores its coordinates, speed, movement type, and related settings. Loading it into another mode applies coordinates only and asks you to review the current setup.
- ArcWayfarer now includes 26 fixed point-route presets covering park, forest, hill, stadium, ticket, supermarket, and shrine locations, plus three nearby templates generated around your current position.
- Personal routes are currently stored in this ArcWayfarer installation. Cross-computer sync is not included in this release.

### More flexible route editing and playback

- Waypoints in Route Loop, Multi-stop, and Flower mode can now be reordered by dragging.
- Flower mode can start from any flower in the route and remembers where you stopped, making it easier to continue the next run.
- Route Loop and Multi-stop now include a 100–1000 km/h Turbo mode for covering long routes or widely spaced stops more quickly.

### Gold Ditto no longer races a fixed timer

- Gold Ditto now uses a guided three-step flow: Fly, Open, and Pull, with the current action clearly shown.
- After reaching the gold flower, ArcWayfarer stays there until you confirm that the Pikmin Bloom pull screen is open instead of returning automatically after a fixed delay.
- Pressing Start pulling immediately begins restoring the location. The three-second countdown tells you how long to keep pulling; it does not delay the restore command.
- The original location can be filled automatically, entered manually, or adjusted on the map. You can also cancel and return to real GPS while waiting.

### Feedback is easier to follow

- Success, warning, and error messages now appear consistently in the bottom-right corner with clearer wording instead of exposing low-level connection details inside panels.
- In multi-device setups, restoring location now shows one result for the device you actually operated instead of repeating the same success notification.
- The top mode switcher now uses compact icons, while Favorites keeps a text label so the main controls remain easy to identify and leave more room for the map.

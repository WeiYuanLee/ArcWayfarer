## 本次更新

### ArcWayfarer 0.1.14 正式公開推出

ArcWayfarer 0.1.14 將位置模擬、路線創作與 iPhone 連線體驗整合為一次正式更新。可在 macOS 或 Windows 上，為 iPhone / iPad 建立可預覽、可控制的個人化移動路線，無需越獄。

### 用路線畫出你的圖案與文字

- 路線循環新增「圖案路徑」模式：可用移動路線建立圓形、方形、三角形、愛心、無限、星形與自訂文字。
- 在地圖上預覽圖案後，可調整大小、旋轉角度與細節程度，製作專屬打卡、活動或地圖藝術路線。
- 自訂文字最多支援 5 個中文字或 12 個英文字母，提供標準黑體與重黑體兩種樣式。
- 修正自訂文字無法載入字型、導致圖案路徑建立失敗的問題。

### 更清楚、更好操作的圖案編輯器

- 圖案改用直覺的圖示卡片選擇，地圖預覽不再被大量數字標記遮住。
- 圖案設定支援捲動；開始執行後會切換為精簡狀態卡片，避免面板出現大量空白。

### iPhone 連線、種花與多裝置改善

- 升級 pymobiledevice3 至 11.3.1，改善新版 iOS 與 macOS 開發服務的連線相容性，並改善部分舊版 iOS 掛載 Developer Disk Image 的穩定性。
- 種花模式在前往下一顆花朵時可設定交通方式與速度，繞花時也會沿用該速度。
- 改善切換裝置時的地圖選點、最後花點與行程紀錄處理，降低多裝置操作時套用到錯誤裝置的風險。
- 修正循環種花第二圈起可能出現的行程紀錄與剩餘時間異常，以及裝置自訂名稱編輯視窗可能被清單遮住的問題。

## What's new

### ArcWayfarer 0.1.14 is now officially available

ArcWayfarer 0.1.14 brings location simulation, route creation, and iPhone connectivity together in one public release. Build and preview personalized movement routes for iPhone and iPad on macOS or Windows, without jailbreaking.

### Draw patterns and text with your route

- Route Loop now includes Pattern Route: create circles, squares, triangles, hearts, infinity symbols, stars, or custom text with a movement route.
- Preview the pattern on the map, then adjust its size, rotation, and detail to create personal check-in, activity, or map-art routes.
- Custom text supports up to 5 Chinese characters or 12 English letters, with Regular and Black sans-serif styles.
- Fixed a font-loading issue that could prevent custom-text pattern routes from being created.

### A clearer, easier pattern editor

- Select patterns from intuitive icon cards, with cleaner map previews that are no longer obscured by waypoint labels.
- Pattern settings remain scrollable, and an active pattern switches to a compact status card to avoid unused panel space.

### iPhone connectivity, Flower mode, and multi-device improvements

- Updated pymobiledevice3 to 11.3.1 for improved compatibility with current iOS and macOS developer services, including more reliable Developer Disk Image mounting on some older iOS versions.
- Flower mode now keeps transport and speed controls available while moving to the next flower and uses that speed while circling.
- Improved map selection, final-flower, and trip-record handling when switching devices, reducing the risk of applying changes to the wrong device.
- Fixed second-lap Flower-mode trip and remaining-time issues, plus a Device Manager custom-name editor layering issue.

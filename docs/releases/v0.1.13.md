## 本次更新

### iPhone 連線底層更新

- 升級 pymobiledevice3 至 11.3.1，改善新版 iOS 與 macOS 的開發服務連線相容性，也修正部分舊版 iOS 掛載 Developer Disk Image 時可能中斷的問題。

### 用路線畫出你的圖案與文字

- 路線循環新增「圖案路徑」模式。現在可以用移動路線畫出圓形、方形、三角形、愛心、無限、星形，或輸入自己的文字。
- 想做專屬打卡路線、活動路線或有趣的地圖圖案，直接選擇圖案、設定大小與方向即可開始預覽。
- 自訂文字支援最多 5 個中文字或 12 個英文字母，並提供標準黑體與重黑體兩種風格。

### 更清楚、更好操作的圖案編輯器

- 圖案選擇改為直覺的圖示卡片，一眼就能找到想要的形狀。
- 地圖預覽更乾淨：不再被大量數字標記遮住，文字與圖案看起來更清楚。
- 可調整圖案大小、旋轉角度與細節程度，方便製作簡潔或精細的路線效果。
- 圖案設定支援捲動，內容較多時仍可順暢查看所有選項與開始按鈕。
- 修正開始執行圖案路徑後，面板可能被撐滿而留下大量空白的問題；執行時會改為精簡的狀態卡片。

### 種花與多裝置體驗改善

- 種花模式在瞬移前往下一顆花朵時，也能設定交通方式與移動速度；繞花時會套用相同速度。
- 修正切換裝置後地圖選點可能套用到另一台裝置的問題，操作多台裝置更安心。
- 修正種花模式設定最後一個花點後切換裝置，可能意外改到原裝置最後座標的問題。
- 修正循環種花進入第二圈後，行程紀錄與剩餘時間可能顯示異常的問題。
- 修正裝置管理的自訂名稱編輯視窗可能被設備清單遮住的問題。

## What's new

### Updated iPhone connectivity

- Updated pymobiledevice3 to 11.3.1 for improved compatibility with current iOS and macOS developer-service connections, including a fix for Developer Disk Image mounting on some older iOS devices.

### Draw patterns and text with your route

- Route Loop now includes Pattern Route. Create circles, squares, triangles, hearts, infinity symbols, stars, or your own text with a movement route.
- Make personalized map art, activity routes, and shareable location designs: choose a pattern, set its size and direction, then preview it on the map.
- Custom text supports up to 5 Chinese characters or 12 English letters, with Regular and Black sans-serif styles.

### A clearer, easier pattern editor

- The pattern picker now uses intuitive icon cards, making it easy to find the shape you want.
- Map previews are cleaner and no longer hidden behind a large number of waypoint labels.
- Adjust size, rotation, and detail level to create either simple or more detailed route designs.
- Pattern settings can scroll when needed, so all options and the Start button remain accessible.
- Fixed an issue where an active Pattern Route could leave the panel expanded with a large empty area; it now switches to a compact status card while running.

### Flower mode and multi-device improvements

- Flower mode now keeps transport and speed settings available when jumping to the next flower, and uses that speed while circling.
- Fixed an issue where a map selection could be applied to another device after switching devices, making multi-device use more reliable.
- Fixed an issue where switching devices after setting the final flower point could unexpectedly change the last coordinate on the original device.
- Fixed trip-record and remaining-time issues that could occur from the second lap onward in looping Flower mode.
- Fixed the custom device-name editor appearing behind the Device Manager list.

## 本次更新

- 地圖會自動記住您最近瀏覽過的區域：再次回到相同地點時，地圖載入更快，也能減少重複下載資料。
- 為日後提供更多地圖來源做好準備，未來可更彈性地切換不同的地圖服務。
- 改善地圖移動體驗：前往很遠的地點時會更快切換；附近移動則維持平順動畫，減少地圖空白或載入延遲的情況。
- 改善縮放與移動地圖時的載入效率，降低地圖服務暫時無法回應的機率。
- 地圖載入時，角落會顯示小型提示，讓您知道地圖仍在載入中。
- 修正收藏地點時的分組選單顯示：下拉箭頭現在會正常顯示；您可直接輸入新分組，或從已有分組中選擇。
- 修正功能說明按鈕的位置：每個功能名稱右側的「ⓘ」說明按鈕已恢復顯示，點選或停留即可查看功能用途。
- 新增 LINE 社群討論區入口：可從左上角選單掃描 QR Code，或直接開啟邀請連結加入社群。
- 改善「路線循環」與「多點巡迴」的道路導航顯示：行進路線與方向箭頭現在會跟著道路轉彎，不會再直接穿越街區。
- 導航模式執行期間，地圖上的方向箭頭也會依照規劃路線前進，讓目前行進方向更容易辨識。

## What's new

- Maps now remember areas you recently visited. Returning to the same location loads faster and avoids downloading the same map data again.
- Prepared the app for more map sources, making it easier to offer flexible map-service options in the future.
- Improved map movement: Jumping to a distant location is now faster, while nearby movements stay smooth. This also reduces blank maps and loading delays.
- Improved map loading while zooming and moving to reduce the chance of temporary map-service interruptions.
- A small indicator now appears in the corner while map data is loading.
- Fixed the group menu when saving a favorite: Its dropdown arrow now displays correctly, and you can either type a new group or select an existing one.
- Fixed the placement of feature help: The ⓘ button is now visible beside every feature name; click or hover over it to see what the feature does.
- Added a LINE community entry: Open it from the top-left menu to scan the QR code or open the invitation link directly.
- Improved road navigation displays in Route Loop and Multi-stop: The route and direction arrows now follow road turns instead of cutting across blocks.
- While navigation is running, direction arrows now follow the planned route so it is easier to see where you are headed.

## 本次更新

- 修正路線循環與多點巡迴在「非直線」道路規劃時，行進亮線與方向箭頭會跨越街區、未沿道路轉彎的問題。
- 目前航段的亮線與動畫現在直接取自地圖上已繪製的藍色道路路徑；箭頭會依道路距離前進，並在轉彎處調整朝向。
- 後端會回傳每個航段的道路幾何，讓前端可可靠對應目前正在執行的航段。

## What's new

- Fixed Route Loop and Multi-stop animations cutting across blocks instead of following turns when road routing is enabled.
- The active highlight and direction arrows now use a slice of the blue road route already drawn on the map. Arrows advance by road distance and turn with the route.
- The backend now returns road geometry per leg so the frontend can reliably identify the active leg.

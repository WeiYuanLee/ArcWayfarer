# ArcWayfarer 使用指南

> 適用於 macOS 與 Windows 的 iPhone GPS 位置模擬工具。

ArcWayfarer 可讓你透過電腦在地圖上設定 iPhone 的模擬位置、沿指定路線移動，或即時控制移動方向。本指南以首次使用者為對象，說明從連接裝置到完成定位的操作流程。

> 請僅在你擁有或獲得授權的裝置與情境中使用本工具，並遵守相關服務與所在地規範。

## 開始前

### 系統需求

- macOS（Apple Silicon 或 Intel），或 Windows 10 / 11 64 位元。
- 以 USB 連接的 iPhone。
- 可正常連線的網路；首次設定位置時需要下載必要的 Apple 開發者服務映像檔。

### iPhone 版本相容性

| iOS 版本 | 開始前需完成的事項 |
| --- | --- |
| iOS 16 及以下 | 以 USB 連接 iPhone、解鎖螢幕，並在手機上選擇「信任這部電腦」。 |
| iOS 17 及以上 | ArcWayfarer 會自動建立所需通道。macOS 可能要求系統授權；Windows 啟動時可能要求系統管理員權限。 |

Windows 使用者若無法偵測裝置，請確認已安裝 iTunes 或 Apple Mobile Device Support。

### 第一次執行

第一次對某部裝置設定位置時，ArcWayfarer 會下載並掛載 Developer Disk Image。依網路與裝置狀況，可能需要數秒到數分鐘；完成後，後續設定通常會更快。

![待補：已連接裝置與主地圖畫面](assets/user-guide/01-connected-device.png)

## 快速開始

以下以「傳送到指定位置」為例。

1. 以 USB 連接 iPhone，解鎖螢幕，並依提示信任電腦。
2. 開啟 ArcWayfarer，確認裝置已出現在裝置選擇區，且連線狀態正常。
3. 使用地點搜尋輸入名稱或地址；也可以直接在地圖上選取位置。
4. 在模式選擇器中選擇 **Teleport／傳送**。
5. 確認地圖上的目標位置，按下主要操作按鈕開始設定。
6. 在 iPhone 的地圖或測試 App 中確認位置已更新。

> 若首次操作正在下載必要檔案，請保持 App 與裝置連線，等待完成後再重試。

## 導航模式

### Teleport／傳送

用於立即將模擬位置切換至任意地點。

1. 搜尋地點，或在地圖上點選目標位置。
2. 選擇 **Teleport／傳送**。
3. 確認位置資訊後執行主要操作。

適用情境：測試地區限定功能、快速切換測試地點，或保護真實位置。

### Navigate／導航

用於讓位置沿真實道路路線前進。

1. 選擇 **Navigate／導航**。
2. 設定起點與目的地。
3. 選擇移動方式或速度，例如步行、慢跑或開車。
4. 確認路線後開始；需要時可暫停或停止。

![待補：導航模式、路線與速度設定](assets/user-guide/02-navigate.png)

### Route Loop／路線循環

用於重複行走同一條預先規劃的路線。

1. 選擇 **Route Loop／路線循環**。
2. 在地圖上建立路線，或匯入 GPX／JSON 路線檔。
3. 設定速度與是否循環。
4. 開始移動；停止後，循環即結束。

匯入前請確認檔案內容與實際順序正確，尤其是包含多個航點的 JSON 檔案。

### Multi-stop／多點路徑

用於依序通過多個航點。

1. 選擇 **Multi-stop／多點路徑**。
2. 在地圖上逐一新增航點。
3. 以拖曳調整航點順序；移除不需要的航點。
4. 設定速度並開始。

適用情境：模擬配送、旅程或需要按固定順序測試的路線。

### Joystick／搖桿

用於即時手動控制移動方向。

1. 選擇 **Joystick／搖桿**。
2. 使用畫面搖桿或鍵盤方向控制移動。
3. 視需要調整速度。
4. 停止控制即可結束移動。

建議先以低速熟悉方向與移動距離。

### Random Walk／隨機漫步

用於在指定範圍內持續隨機移動。

1. 選擇 **Random Walk／隨機漫步**。
2. 在地圖上指定中心點或活動區域。
3. 設定移動範圍與速度。
4. 開始後，位置會在設定範圍內隨機移動；可隨時停止。

## 常用功能

### 搜尋地點

在地點搜尋欄輸入地名、地址或關鍵字，選取結果後即可在地圖上定位。搜尋結果可作為傳送目的地、路線終點或新航點。

### 收藏

將常用位置加入收藏，避免重複搜尋。

- 可建立群組分類位置。
- 可拖曳調整位置或群組順序。
- 從收藏中選取位置後，可直接套用到目前模式。

### 歷史記錄

歷史記錄會保留最近使用的位置。當你需要回到剛剛的測試地點時，從歷史中選取即可快速重新設定。

### 命令面板

按下 `⌘K`（Windows：`Ctrl+K`）可開啟命令面板，快速尋找：

- 導航模式。
- 收藏或歷史位置。
- 常用操作與設定。

## 手機遙控

Mobile Remote 可讓你用手機操作桌面版 ArcWayfarer。

1. 在桌面版開啟手機遙控功能。
2. 以手機掃描畫面上的 QR Code。
3. 在手機瀏覽器開啟配對頁面並完成連線。
4. 使用手機介面搜尋位置、切換模式或執行控制操作。

配對時，手機與執行 ArcWayfarer 的電腦通常需要在可互相連線的網路環境中。

## 多裝置管理

若同時連接多台 iPhone：

1. 在裝置選擇器中切換目標裝置。
2. 每次執行操作前，確認目前選取的是正確裝置。
3. 依序設定各裝置的位置或路線。

建議在多裝置測試時，為每部裝置使用不同的收藏群組或清楚命名的常用位置，降低操作到錯誤裝置的機會。

## 停止模擬位置

當你要結束移動或切換測試情境時：

1. 在目前模式的控制面板中按下 **停止**。
2. 確認路線、搖桿或隨機漫步已停止。
3. 若要回到其他位置，使用 Teleport 設定新位置，或結束測試後重新連接裝置。

不同 iOS 版本與使用中的 App 對位置更新的反應可能略有差異；若畫面沒有立即更新，請重新開啟該 App 或稍候片刻。

## 疑難排解

### 找不到 iPhone

依序檢查：

1. USB 線材與連接埠是否正常。
2. iPhone 是否已解鎖。
3. 手機是否出現「信任這部電腦」提示；若有，請選擇信任。
4. Windows 是否已安裝 iTunes 或 Apple Mobile Device Support。
5. 重新插拔裝置後，重新啟動 ArcWayfarer。

### iOS 17 以上無法開始操作

- macOS：確認已允許系統顯示的授權要求。
- Windows：以系統管理員身分啟動 ArcWayfarer，並確認 Apple 相關驅動已正確安裝。
- 保持 USB 連線、不要讓 iPhone 鎖定，然後重試。

### 第一次設定位置很久沒有完成

首次操作可能正在下載或掛載 Developer Disk Image。請確認網路可用、不要拔除裝置，並等待幾分鐘。若仍未完成，重新啟動 App 後再試一次。

### 地圖或測試 App 沒有立即更新位置

- 確認 ArcWayfarer 顯示操作已成功。
- 在 iPhone 上重新開啟目標 App。
- 確認不是正在查看快取中的地圖資訊；稍候片刻後再檢查。
- 重新執行一次 Teleport，確認目標位置。

### 手機無法連上 Mobile Remote

- 重新產生 QR Code 並再次掃描。
- 確認手機與電腦位於可互相連線的網路。
- 檢查電腦防火牆或公司網路是否封鎖本機連線。
- 關閉手機瀏覽器頁面後重新配對。

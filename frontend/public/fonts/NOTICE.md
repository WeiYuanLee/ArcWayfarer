# Text route fonts

`NotoSansCJKtc-Regular.otf` and `NotoSansCJKtc-Black.otf` are Noto Sans CJK TC fonts from the Noto CJK project.

- Source: https://github.com/notofonts/noto-cjk
- License: SIL Open Font License 1.1
- Purpose: offline glyph-outline generation for custom text routes

The complete license and copyright notice must remain with this font in distributed builds.
